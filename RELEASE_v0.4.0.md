# ALI Simulations v0.4.0 — Persistent Organization Administration

First functional Platform Administration build.

- Live dashboard counts from PostgreSQL
- Organization directory
- Create and edit organizations without replacing existing rows
- Organization branding fields: title, tagline, subscript, logo URL
- License status and active/inactive controls
- Organization simulation entitlements for Belonging and CityLab
- Idempotent simulation catalog seeding
- Audit events for organization create/update and entitlement changes
- Platform-admin protected API routes
- Existing v0.3.1 database is preserved; no destructive migration is included

Initial recommended real record: Early Learning Collective.

# ALI Simulations v0.7.0 — Belonging Operations & Network

- Participant My Network with personal contacts plus automatic organization/shared contacts.
- Reusable case-insensitive search and sortable contact directory UI across non-sensitive contact fields.
- Belonging Leadership Challenge workspace grounded in VOICE → CHOICE → AGENCY → IMPACT.
- Multi-category collections: Food, Toys, Clothing, School Supplies, Hygiene Essentials, Winter Warmth, and custom categories.
- Each category supports in-kind goods and optional monetary donations without converting dollars into item counts.
- Community partner records.
- Two-team challenge bootstrap and six leadership role keys: Team Lead, Data Analyst, Logistics / Traffic Flow Coordinator, Community Liaison, Quality Control, Communications Lead.
- Event-level collection transactions with category/team, in-kind vs monetary, donor/designation, quantity/amount, QC status and notes.
- Outreach/activity logging for team work beyond donations.
- Forward-only Alembic migration 0003; existing organization, person, membership and authentication data are preserved.

The operational data model intentionally leaves disruption/evaluation/awards for the next simulation-focused release.

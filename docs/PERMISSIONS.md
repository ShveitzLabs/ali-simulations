# Roles and Permissions

Roles are bundles of granular capabilities. UI navigation is generated from permissions; inaccessible functions are not merely disabled visually.

## Roles
- **Platform Administrator** — platform ownership; organizations, licensing, simulation entitlements, scenario design/test/publish, platform branding/templates, security, support, audit and administrative data access.
- **Organization Administrator** — administers licensed functionality within one organization; people, sessions, branding, consent, evaluation governance, communications and curated reports/exports.
- **Organization Viewer** — read-only organization dashboards, aggregate outcomes and published/curated reporting; no raw/confidential evaluations or mutations.
- **Session Administrator** — manages assigned sessions, participants, teams, evaluator assignments, simulation operation, evaluation windows, approval and participant release.
- **Simulation Leadership Staff** — operational session access and repeated participant observations.
- **Evaluator / Judge** — assigned evaluation access only; no other evaluators' submissions or unreleased results.
- **Participant** — assigned simulation experience, role-specific information, contacts, peer feedback and released leadership results.
- **Facilitator / Volunteer** — minimum operational access required for assignment.

## Evaluation safeguard
No user may approve, exclude/reject, or release their own submitted evaluation/observation. Another Session Administrator or Organization Administrator must perform that action.

## Scenario design
Scenario design, cloning of master content, testing, publishing and retirement are Platform Administrator capabilities only. Organizations consume entitled, published scenarios and configure only permitted session-level options.

## Licensing
Only Platform Administrators may change organization license status/expiration, membership access expiration, or organization simulation entitlements.

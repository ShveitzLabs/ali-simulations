# ALI Simulations v0.6.0 — Membership, Access & Public Experience

- Public three-pane cycling ALI Simulations welcome experience with secure sign-in.
- Platform Admin can enable a Person for multiple organizations and assign organization roles.
- Organization People & Contacts is automatically derived from active memberships.
- Platform Admin can set/reset a temporary password; only the hash is stored and first login forces password replacement.
- Authenticated non-platform-admin users receive a private member welcome screen showing organizations and roles.
- Membership disablement is non-destructive and access/membership changes are audit logged.
- No destructive schema migration is required for this release.
